Quem Pegoua Torta?

Como jogar

A torta da festa surpresa da Applejack sumiu! Ande por Ponyville, converse com as pôneis e junte as pistas para descobrir quem pegou.

No computador

  • AD ou setas: andar
  • E, Enter ou Espaço: conversar, abrir baús e avançar o diálogo
  • Clique no cenário para andar até lá

No celular

  • Segure os botões das pontas para andar
  • Toque no cenário para andar até lá
  • Use o botão do meio para interagir

Algumas casas escondem baús com ingredientes. Junte os quatro para um final especial.
